# Forge Jean-Petit

Private booking app for the seven families sharing Forge Jean-Petit.

- Hosted with GitHub Pages: https://gvercauteren-prog.github.io/forges/
- Sign-in (Google) and data (Firestore) run on the Firebase project `forge-jean-petit`.
- `firestore.rules` holds the security rules; paste them in Firebase console → Firestore Database → Rules.
- Only Gmail addresses added in the app's Admin tab can sign in.

To update the app, replace `index.html`.
